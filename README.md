# Polynomial Regression

Overview: Polynomial regression with OLS, Ridge, and Lasso, using 5-fold cross-validation for model selection.

- `training.py` — Tests polynomial degrees and selects the best OLS/Ridge/Lasso model for both problems.
- `BT2024169_var1.py` — Trains the final Lasso polynomial model for Problem 1 and generates predictions.
- `BT2024169_var2.py` — Trains the final Ridge polynomial model for Problem 2 and generates predictions.
- `*_train_*.csv` / `*_test_*.csv` — Training and testing datasets.
- `*_pred_*.csv` — Final prediction outputs.
